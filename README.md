# OpenGate

Spectreasy (or OpenGate) is temporarily unavailable while development is paused for manuscript submission.

## Feature overview

OpenGate is a local-first flow-cytometry workbench for:

- recursive FCS dataset discovery and panel and metadata review
- branching Dataset → Preprocessing → Gating workflows
- rectangle, ellipse, polygon, quadrant, histogram, and Boolean gates
- clustering, dimensional reduction, trajectory inference, and annotation
- population statistics, figures, reports, and comparison diagnostics
- reproducible project-local caches, exports, and task provenance
